Design a complete modern web application UI prototype for a hospital management system called ACUTIX.

The interface should replicate the structure of an existing hospital management prototype system, keeping the same modules and workflow but with significantly improved UI design, usability, and modern dashboard layout.

The design should look like a professional SaaS healthcare platform dashboard.

BRANDING
Use the ACUTIX logo colors as the UI theme.

Primary color: deep navy blue
Accent colors: cyan, teal, and gold gradients from the logo.

Recommended palette:

Primary: #1F2A5A
Accent: #3CC0D0
Gradient: #F6C177 to #5ED3CF
Background: #F4F7FB
Cards: #FFFFFF

Use soft shadows, rounded cards, modern typography, and clean spacing.

Fonts: Inter or Poppins.

GLOBAL LAYOUT

Structure:

Main content area displaying cards, charts, tables, and forms.
